Coding Challenges

Pick one of three changes that would take half a day by hand. Twenty minutes with an agent that can see the whole repo.

What to do

  1. Jump to the starting checkpoint, so everyone begins the challenge from the same code.
  2. Get a shell in the container and start Claude Code there. It runs inside the container all day — that is what keeps it away from the rest of your machine.
  3. Pick one challenge and paste its prompt.
  4. Let the agent find the files itself. You do not need to know the layout, and you should not go hunting for the right folder first — the point of the exercise is that the agent has the whole repo in context and you do not.
  5. Run ./scripts/ci-check.sh in the container when you think you are done, and read what the agent changed before you believe it.

Prompts — copy, don't retype

Challenge 1 — Refactor-Rename
Rename 'Campaign' to 'Proposal' across the entire codebase, including API endpoints, documentation, and database references. Update the tests to match and make sure they still pass.
Challenge 2 — Observability
Add structured JSON request logging using the existing pino logger. Each log line should include the method, path, status code, duration in milliseconds, and a correlation ID that follows the request through the system.
Challenge 3 — New Feature
Add a 'Trending Missions' section to the Explore page: the three most popular live campaigns by contributor count, shown above the main grid. Match the existing page's styling and add tests.

You are done when

The change is applied across every file it touches — including the ones you would have forgotten — and the tests still pass.
