The three commands

Prove your environment works — run once, before we start
./verify.sh
See every checkpoint and where you are
./checkpoint.sh --list
Jump to checkpoint N — your work is parked first, never lost
./checkpoint.sh 4

If you fall behind

You are never locked out. Jumping to a checkpoint commits whatever you had in progress to a wip/ branch before it moves you, so you can always get back to it:

Find work an earlier jump parked for you
./checkpoint.sh --parked

Falling behind in one activity costs you that activity — nothing after it.
