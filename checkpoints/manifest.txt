# Checkpoint ladder — single source of truth.
#
# Activity N produces cp-N: the tag number is the activity number.
# A long activity also has lettered rungs part-way through it (cp-08a, cp-08b, cp-08c), between
# cp-(N-1) and cp-N, so falling behind mid-activity is one jump, not the whole activity.
# The team activity between 02 and 03 is in the room and produces nothing.
#
# Format:  tag | title | what this checkpoint contains | what it unblocks
#
# Read by ./checkpoint.sh. Keep the pipes; keep the tags in ascending order.
# A tag listed here that does not exist yet in git is reported as "not published"
# rather than failing — that is how a partially-built ladder stays usable.
